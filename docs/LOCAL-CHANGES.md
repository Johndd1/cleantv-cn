# 本地完善版 1.16-home.2-local

基线：Jimu888/home-tv-cn `6d755c1bc995d712610acde8eb93e10a640c74c6`。
参考：Gathin23/cleanyourtv `56cd3e81c062244ea313899d5af8d75294f2daae`。

## 改了什么

1. 新安装工具把预览、仅安装试用、桌面接管分开；接管前按设备 ID 保存原桌面、权限和服务状态。重试保留原始记录，恢复完毕后再次安装会开启新的记录周期。
2. 恢复明确设置原桌面组件，并撤回本次接管权限；合并处理无障碍/通知监听，不覆盖安装后新增的其他服务。恢复失败保留记录并返回非零状态；无记录时拒绝猜测。
3. 首页设置保存应用选择与顺序，支持 1–12 个包名，可选择电视实际安装的不同渠道版。保留原默认应用顺序。
4. 全部应用长按确认键显示添加到首页、隐藏、应用信息和卸载菜单；隐藏应用有独立恢复列表。隐藏应用不再混进“全部应用”及首页。
5. 投屏/硬盘优先采用用户指定应用，其次尝试已安装的小米/TCL 应用与平台入口；没有可用入口时提示选择应用。没有继承参考项目的跨品牌测试结果。
6. “首页设置”实际连接红蓝/纯深色背景、焦点边框及快捷入口设置。保留系统屏保和电源策略，不接入上游手机设置服务器。

## 有意限制的范围

- 不自动停用、卸载原厂应用，不导入参考项目的 debloat 名单。
- 不自动绕过固件安装验证，不自动切换 guard APK，不开启持久 ADB。
- 系统报告已是默认桌面却仍返回原厂首页时，可在确认设备行为后使用 `install.sh --force-guard`。与需要单独构建的 `install.sh guard` 不同，前者仍使用 standard APK。
- 新安装只在确有需要时授予守护权限，不额外授予定位、修改亮度或 TCL 私有自启动权限。因此，亮度控制、Wi-Fi 名称显示和部分固件的重启接管仍可能受限。
- 恢复记录不是原 APK、应用私有配置或数据备份；也不能回滚旧脚本已经做过、但没有记录的设置。当前安装工具仅支持主用户 0。
- 本地构建使用本机签名，与作者或上游发布包签名不同；禁止把签名冲突处理成自动卸载。

## 验证边界

Python 回归测试采用模拟设备，验证原始记录保留、恢复失败、权限恢复、跨设备拒绝执行以及保留新增服务等行为。Kotlin 单元测试验证首页配置边界与排序。编译、lint 和实际 APK 信息另见交付包中的验证记录。

本次没有连接电视，界面遥控器操作、型号适配、Home 键、待机唤醒、重启接管、投屏和媒体播放仍待真机验收。原版截图只用于理解原有外观。
